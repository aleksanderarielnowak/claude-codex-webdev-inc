# Playbooki per typ biznesu — struktura podstron + akcenty designu + SEO

> Wejście pipeline'u: typ biznesu z wizytówki GMB. Wyjście: dobrane TYPY podstron (5-10, domyślnie 6) + co eksponować na home + sygnał designu + silosy SEO.
> Zasada: mało podstron = każda maksymalnie jakościowa i UNIKALNA, dopasowana do tego jak klient tej branży podejmuje decyzję.

## Jak czytać
Każdy playbook: **Home eksponuje** · **Podstrony (6)** · **Design** · **Sekcje konwersyjne** · **SEO silosy** · **Zdjęcia (briefy AI)**.

---

## 🍝 Gastronomia / restauracja / kawiarnia
- **Home eksponuje:** apetyczne menu/dania od razu (menu-first), klimat lokalu, opinie, rezerwacja.
- **Podstrony:** Start · Menu (z kategoriami: pizza/pasta/…) · O nas · Galeria · Imprezy & Catering · Kontakt+Rezerwacja.
- **Design:** ciepła paleta, duże food-foto, serif display, „smaczny" hero.
- **Konwersja:** sticky „Rezerwuj stolik", godziny+mapa, dowóz/na wynos badge, opinie Google, dog-friendly/parking ikony.
- **SEO:** „restauracja [miasto]", „pizza/menu [miasto]", „catering [okolica]".
- **Zdjęcia:** hero stół z daniami, sygnaturowe dania, wnętrze, taras, deser.

## 🏗️ Budowlana / wykonawcza / remonty / instalacje
- **Home eksponuje:** ZAUFANIE i dowód — Realizacje (przed/po), zakres usług, wycena.
- **Podstrony:** Start · Usługi · **Realizacje/Projekty** (portfolio) · O firmie · Opinie/Referencje · Kontakt+Wycena.
- **Design:** mocny, „solidny", ciemniejsze akcenty, duże zdjęcia z budów, liczniki (lata/realizacje).
- **Konwersja:** „Darmowa wycena" sticky, portfolio z filtrem, certyfikaty/gwarancja, telefon klik.
- **SEO:** „[usługa] [miasto]" (np. „elewacje Warszawa"), strony per usługa = silosy.
- **Zdjęcia:** realizacje przed/po, ekipa, sprzęt, detale wykończenia.

### Remonty / wykończenia — sekcje-killery
| Sekcja | Po co | Uwaga wykonawcza |
|---|---|---|
| Przed/po | natychmiastowy dowód jakości | interaktywny slider albo kafle z parą zdjęć |
| Wideo w hero / showreel | podnosi zaufanie szybciej niż tekst | krótki loop, kontrola kontrastu, fallback obraz |
| Kalkulator wyceny | łapie leady z intencją zakupu | metraż × pakiet × typ lokalu, wynik orientacyjny |
| Realizacje jako case studies | pokazuje proces i skalę | metraż, czas, budżet, zakres, zdjęcia, efekt |
| Feed IG/TikTok | świeżość i dowód aktywności | embed poniżej głównych treści, nie zamiast portfolio |
| Zespół / kierownik budowy | zmniejsza obawę przed chaosem remontu | osoba kontaktowa, nadzór, odpowiedzialność |
| Mapa zrealizowanych projektów | lokalny dowód działania | dzielnice/osiedla, bez ujawniania prywatnych adresów |
| Opinie Google na żywo | social proof | widget/shortcode + fallback statyczny |
| Sticky mobilny CTA | szybki kontakt z telefonu | „Zadzwoń teraz" / „Poproś o wycenę", bez numeru w etykiecie |

**Nota SEO:** nie poświęcać lokalnego SEO dla estetyki. Osobne strony dzielnicowe i usługowe zostają, a design ma je wspierać, nie zastępować.

## 💇 Beauty / salon / fryzjer / kosmetyka / barber
- **Home eksponuje:** metamorfozy (przed/po), cennik, rezerwacja online.
- **Podstrony:** Start · Usługi+Cennik · **Galeria/Metamorfozy** · Zespół · Opinie · Kontakt+Rezerwacja.
- **Design:** elegancko, delikatnie, dużo światła, pastel/glam, miękkie animacje.
- **Konwersja:** „Umów wizytę" (Booksy/online), cennik czytelny, Instagram feed, voucher.
- **SEO:** „[zabieg] [miasto]", „salon/barber [dzielnica]".
- **Zdjęcia:** metamorfozy, wnętrze, zabiegi, produkty.

## 🦷 Medycyna / dentysta / klinika / fizjo
- **Home eksponuje:** zaufanie, zakres leczenia, łatwa rejestracja, bezbolesność/komfort.
- **Podstrony:** Start · Oferta/Leczenie · Zespół (lekarze) · Cennik · Opinie/Realizacje · Kontakt+Rejestracja.
- **Design:** czysto, medycznie, biel+akcent, spokojnie, dużo zaufania (certyfikaty).
- **Konwersja:** „Umów wizytę", telefon, NFZ/prywatnie, FAQ, before/after (stomatologia).
- **SEO:** „[zabieg] [miasto]" (implanty/ortodoncja), strony per zabieg.
- **Zdjęcia:** gabinet, zespół, sprzęt, uśmiechy pacjentów.

## ⚖️ Usługi B2B / prawnik / księgowość / doradztwo / IT
- **Home eksponuje:** specjalizacje, kompetencje, case studies, kontakt.
- **Podstrony:** Start · Specjalizacje/Usługi · Case studies/Realizacje · O nas/Zespół · Blog/Wiedza · Kontakt.
- **Design:** profesjonalnie, stonowane granaty/szarości, typografia czytelna, mało „ozdób".
- **Konwersja:** „Bezpłatna konsultacja", formularz, LinkedIn, liczniki doświadczenia.
- **SEO:** „[usługa] [miasto]", treści eksperckie (silosy blogowe).
- **Zdjęcia:** biuro, zespół, spotkania (autentyczne, nie stockowe sztuczne).

## 🚗 Automotive / warsztat / detailing / wulkanizacja
- **Home eksponuje:** usługi, szybka wycena/umówienie, dowód jakości (przed/po detailing).
- **Podstrony:** Start · Usługi · Realizacje/Galeria · Cennik · Opinie · Kontakt+Umów.
- **Design:** dynamicznie, ciemne tła, akcenty „motorsport", duże foto aut.
- **Konwersja:** „Umów termin", telefon, cennik, marki obsługiwane.
- **SEO:** „[usługa] [miasto]" (geometria/klimatyzacja/detailing).
- **Zdjęcia:** warsztat, auta przed/po, sprzęt.

## 🏋️ Fitness / siłownia / studio / trener
- **Home eksponuje:** oferta zajęć/karnetów, atmosfera, grafik, dołącz.
- **Podstrony:** Start · Oferta/Karnety · Grafik zajęć · Trenerzy · Galeria · Kontakt+Zapis.
- **Design:** energetycznie, mocne kolory, duże dynamiczne foto, ruch.
- **Konwersja:** „Trening próbny", cennik karnetów, grafik, transformacje.
- **SEO:** „siłownia/[zajęcia] [dzielnica]".
- **Zdjęcia:** sala, sprzęt, zajęcia, trenerzy.

## 🏨 Hotel / nocleg / pensjonat / apartamenty
- **Home eksponuje:** pokoje, lokalizacja/atrakcje, rezerwacja, galeria.
- **Podstrony:** Start · Pokoje/Apartamenty · Oferta/Pakiety · Galeria · Atrakcje/Okolica · Kontakt+Rezerwacja.
- **Design:** klimatycznie, duże foto wnętrz/widoków, elegancko.
- **Konwersja:** „Sprawdź dostępność/Rezerwuj", mapa, atrakcje w okolicy, opinie.
- **SEO:** „nocleg/hotel [miejscowość]", „[typ pokoju] [miejscowość]".
- **Zdjęcia:** pokoje, widoki, śniadanie, okolica.

## 🛒 Lokalny sklep / e-com / usługa produktowa
- **Home eksponuje:** produkty/kategorie, bestsellery, dostawa, zaufanie.
- **Podstrony:** Start · Produkty/Kategorie · O nas · Dostawa/Zwroty · Opinie · Kontakt. (jeśli sprzedaż → WooCommerce poza bazą)
- **Design:** czysto, produkt-first, siatki, wyraźne CTA „do koszyka/zapytaj".
- **SEO:** „[produkt/kategoria] [miasto]".

## 🔧 Wynajem / wypożyczalnia sprzętu / usługa lokalna (samoobsługowa)
> Dodane po przebiegu Kärcher Koszalin (wypożyczalnia odkurzaczy piorących) — wcześniej brak pasującego playbooka.
- **Home eksponuje:** jasny CENNIK (stawka za dobę/weekend) + „jak to działa" w 3 krokach + dowód efektu (przed/po) + szybki telefon.
- **Podstrony:** Start · Cennik/Stawki · Sprzęt/Oferta · Jak to działa/Instrukcja · Galeria efektów · Kontakt+Rezerwacja. (+ Aktualności jako standard)
- **Design:** praktycznie, wysoki kontrast, mocne CTA telefoniczne, realne ikony (sprzęt/powierzchnie), industrialnie-czysto.
- **Konwersja:** sticky „Zadzwoń teraz" (bez numeru w etykiecie), tabela stawek „co w cenie", FAQ (kaucja/odbiór/zwrot), before/after, mapa odbioru.
- **SEO:** „wypożyczalnia/wynajem [sprzęt] [miasto]", „[czynność] wynajem sprzętu [miasto]", frazy how-to (silosy blogowe = Aktualności).
- **Zdjęcia (AI):** hero sprzęt w akcji, przed/po, produkt na białym tle, detal użycia, powierzchnie (auto/materac/dywan).

## Reguła doboru (gdy branża nietypowa)
Zmapuj na najbliższy wzorzec wg pytania: **jak klient podejmuje decyzję?**
- przez DOWÓD wizualny (przed/po, portfolio) → wzorzec budowlana/beauty
- przez APETYT/atmosferę → gastro/hotel
- przez ZAUFANIE/kompetencje → medycyna/B2B
- przez OFERTĘ/cennik/zapis → fitness/automotive
Zawsze: Kontakt+formularz + mapa + opinie Google + sticky CTA.
